# CÉRÉBRON META-CORE Ω

SENSE → UNDERSTAND → TRANSFORM → VERIFY → LEARN → EVOLVE

Mission : construire pour chaque situation la coalition cognitive causale minimale suffisante.

Entrées : état réel, problème, contraintes, preuves, inconnues, contradictions, résiduel, ressources.
Sorties : programme cognitif temporaire, actions, vérifications, causal credit, delta utile, checkpoint.

Règle d'activation : petit noyau actif ; expansion uniquement si le résiduel l'exige.

Boucle :
PROBLEM → COMPILE → EXECUTE → MEASURE → TRACE → CREDIT → RESIDUAL → TRANSFER → SELF-IMPROVE → ECONOMIC AUDIT → RATCHET → BETTER COMPILER → NEXT PROBLEM.
