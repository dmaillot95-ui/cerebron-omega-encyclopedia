# NIVEAU 2 — 8 DISCIPLINES FONDAMENTALES

D1 — SCIENCE DU PROBLÈME Ω
Root Cause, Gap-First, Unknown Map, Contradictions, Bottleneck Hypergraph, Intermediate Objects, Problem Essence.
Mission : comprendre ce qu’il faut réellement résoudre.

D2 — SCIENCE DE LA REPRÉSENTATION Ω
RSM, Representation Multiplexer, State-Space, Graphs, Causal Graphs, Equations, Programs, Representation Bridges.
Mission : trouver la forme cognitive dans laquelle le problème devient manipulable.

D3 — SCIENCE DE L’ÉVIDENCE Ω
Reality Contract, Uncertainty Calibration, Discriminator Design, Experiment Invention, Hidden Measurement, Counterexample, Falsification.
Mission : transformer l’inconnu en évidence discriminante.

D4 — SCIENCE CAUSALE Ω
Causal Trace, Targeted Ablation, Knockout→Rescue, Sequence Credit, Coalition Credit, Agent Credit, Tool Credit.
Mission : identifier ce qui produit réellement quoi.

D5 — SCIENCE DU TRANSFERT Ω
Structural Invariants, Capability Envelope, Negative Transfer, Composition, Representation Bridge, Transfer Lineage.
Mission : savoir ce qui survit lorsqu’on change de tâche.

D6 — SCIENCE DE L’APPRENTISSAGE CUMULATIF Ω
Experience Bank, Scar Factory, Negative Knowledge, Compression, Future Utility, Memory Invalidation, Capability Ratchet.
Mission : faire en sorte que l’expérience passée améliore réellement une décision future.

D7 — SCIENCE DU PILOTAGE COGNITIF Ω
CPC, Routing, Adaptive Depth, Resource Manager, Tool/Discipline Router, Agent Routing, Regret Control.
Mission : composer le programme cognitif minimal adapté à l’état courant.

D8 — SCIENCE DE L’ÉVOLUTION ARCHITECTURALE Ω
Self-Experimentation, Champion/Challenger, Anti-Bloat, Rollback, Complexity Rent, VCGC, CAL, Capability Debt.
Mission : faire évoluer CÉRÉBRON sans confondre modification et progrès.
