# NIVEAU 1 — 12 MACROGRAINS RACINES

MG-01 ROOT DIAGNOSTIC — Surface → Structure → Root → Bottleneck.
MG-02 REALITY CONTRACT — Claim → Prediction → Observation → Residual.
MG-03 REPRESENTATION ESCAPE — Block → Representation Shift → Retest.
MG-04 MINIMUM SUFFICIENT CHANGE — Gap → Smallest useful intervention.
MG-05 DISPUTE TO DISCRIMINATOR — Competing hypotheses → cheapest separating test.
MG-06 CAUSAL CREDIT — Outcome → contribution → ablation → credit.
MG-07 RESIDUAL LEARNING — Failure/Success → unexplained residual → next information.
MG-08 VERIFIED TRANSFER — Mechanism → invariant → boundary → new context → test.
MG-09 EXPERIENCE COMPRESSION — Experiences → mechanism + scars + exceptions.
MG-10 REGRET-BOUNDED ROUTING — Problem state → route → baseline → regret → update.
MG-11 VERIFIED SELF-IMPROVEMENT — Mutation → shadow → hidden/OOD → ratchet.
MG-12 COGNITIVE ECONOMICS — Verified gain → total cost → Pareto → prune.

Les macrograins spécialisés plus anciens sont descendants, variantes ou compositions de ces racines sauf preuve qu’un objet distinct est nécessaire.
