# NIVEAU 0 — 3 GRAINES MÈRES

## GRAINE Α — COMPRENDRE
Question : qu’est-ce qui se passe réellement et qu’est-ce qui bloque ?
Chaîne : Distinction → Relation → Structure → Reality → Root Question → Gap → Unknown → Contradiction → Constraint → Bottleneck → Representation Shift.

## GRAINE Β — TRANSFORMER
Question : quel changement minimal peut modifier réellement l’état ?
Chaîne : Lever → Minimum Sufficient Change → Action → Tool → Experiment → Counterexample → Falsification → Ablation → Causal Credit.

## GRAINE Ω — ÉVOLUER
Question : qu’est-ce qui doit être conservé afin que le futur soit meilleur ?
Chaîne : Residual → Experience → Scar → Compression → Boundary → Transfer → Future Utility → Capability → Routing Update → Anti-Bloat → Recompile.

Compression racine : COMPRENDRE → TRANSFORMER → ÉVOLUER.
